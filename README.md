# Hey, ik ben TwoChill 👋
Zelfgeleerde hobby-developer uit Amsterdam. Ik bouw dingen als een idee sterk genoeg is om het te eisen — automatiseringstools, OSINT-utilities, crypto-trackers, AI-workflows, en af en toe een tekst-RPG.

Achtergrond in digitaal onderzoek en operationele IT. Python sinds 2020, altijd bouwen naar een doel.

---

## Wat me drijft
Ik ben geen leerboek-developer. Ik leer door te bouwen richting een doel, niet door te studeren voor een examen.  
AI heeft dat spel volledig veranderd — Claude Code in het bijzonder heeft de kloof tussen *een idee hebben* en *iets echts opleveren* weggevaagd.  
Op dit moment ben ik diep bezig met AI-agents, sub-agents, en wat er mogelijk wordt als je een capabel model in een volledige toolchain zet.

---

## Waar ik nu aan werk
- **Claude Code workflows** — het onder de knie krijgen als build-tool, niet alleen als code-assistent
- **Shadowcast** — autonome social media agent: stemmingsbewust posten, Discord-goedkeuringslaag, volledig geheugenloop
- **zzp-brain** — privé Obsidian-kenniswiki voor Nederlands belasting- en ZZP-recht, gebouwd met Claude Code
- **AI agent-architecturen** — persoonlijke assistenten, geautomatiseerde pipelines, agentische OSINT
- **RotDR** — mijn tekst-RPG die ik ooit zal afmaken. Binnenkort™.
