# Hey, I'm TwoChill 👋

Self-taught hobby developer from Amsterdam. I build things when an idea is strong enough to demand it — automation tools, OSINT utilities, crypto trackers, AI workflows, the occasional text RPG.

Background in IT management and digital investigation. Python since 2020, on and off.

---

## What drives me

I'm not a textbook developer. I learn by building toward a goal, not by studying for an exam.  
AI changed that game entirely — Claude Code in particular collapsed the gap between *having an idea* and *shipping something real*.  
Right now I'm deep into AI agents, sub-agents, and what becomes possible when you wire a capable model into a full toolchain.
